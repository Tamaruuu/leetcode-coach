# 🧠 LeetCode Coach

一个帮你**成为大师级力扣选手**的个人小工具。核心不是记录刷题量，而是
**间隔重复（SM-2）+ 弱点定位**——和 Anki 同款的科学复习算法，让你把脑子里的
"算法模式库"真正建牢。

## 启动

```bash
cd ~/leetcode-coach
./start.sh
```

浏览器会自动打开（默认 http://localhost:8501）。数据存在本地 `leetcode.db`，纯私有。

## 题库（4350 道题，可搜索选题）

录题时不用手敲题号/标题/链接——本地已内置力扣全部题目元数据，
在『添加题目』页搜索（题号/中文/英文）即可选题，标题、难度、链接、官方标签自动带出，
你只需打自己的模式标签 + 记笔记 + 打分。

题库由脚本生成，需要刷新时重跑：

```bash
./.venv/bin/python fetch_problems.py
```

> 只拉公开元数据（题号/标题/难度/官方标签/链接），不含题目正文。


## 四个页面

| 页面 | 作用 |
|------|------|
| 📅 今日复习 | SM-2 算出今天该复习哪些题，做完打分自动安排下次复习日 |
| ➕ 添加题目 | 录入新题 + 打模式标签（弱点分析的基础）+ 首次表现 |
| 📊 弱点分析 | 按模式统计平均掌握度/用时，自动把你最薄弱的模式排在最前 |
| 📚 题目列表 | 全部题目总览 |

## 怎么用才有效

1. **每做一道新题就录进来**，认真打模式标签和"思路触发点"笔记。
2. **每天先打开『今日复习』**，把到期的题重做一遍，凭真实表现打分——
   秒了就间隔拉长，卡住就明天再来。
3. **定期看『弱点分析』**，针对排在最前的薄弱模式去力扣找同类题刷。

> 表现打分对应的复习质量：秒了=5，想了挺久=3，看了提示=2，不会=0。
> 质量 ≥3 才算"掌握"，间隔才会增长。

